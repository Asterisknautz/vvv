# リポジトリ整備方針

## 現状

- Vite + Three.js の実験コードは `src/` にまとまっている。
- 実験 003 の YAML 仕様が `config/` にあり、実行コードとの関係が曖昧だった。
- 古いセットアップ手順が `docs/` 直下にあり、現行コードとの差分も混ざっていた。
- バンドル分析の `stats.html` がルート直下に生成される設定だった。

## 整理後の役割

- `src/`: 実行される Web アプリのコード。
- `src/ideas/`: 3 桁 ID の実験モジュール。
- `experiments/`: 実験単位の仕様、プロンプト、検討メモ。
- `public/`: URL で公開される静的ファイル。
- `docs/`: 人間と Codex が読む運用、設計、調査メモ。
- `docs/archive/`: 古いセットアップ手順や履歴資料。
- `reports/build/`: ビルド分析などの生成レポート。

## 今回の移動

- `docs/setup_md_asterisknautz.md` を `docs/archive/251025_初期セットアップメモ.md` に移動。
- `config/003.yaml` を `experiments/003_calm_aquarium.yaml` に移動。
- バンドル分析の出力先を `stats.html` から `reports/build/bundle-stats.html` に変更。

## 次に整える候補

- `src/threeScene.ts` が大きくなっているため、遷移演出、入力、描画基盤を分割する。
- `index.html` のナビゲーションを手書きから実験メタデータ駆動にする。
- `src/ideas/004.ts` と `src/ideas/005.ts` は blueprint のみなので、仕様を `experiments/` に寄せるか、実装モジュールに発展させるか決める。
